# nvim-config
Various configuration and plugin files for neovim

## Troubleshooting
1. This git repository should be cloned into ~/.config/nvim/
2. Will likely have to install a newer version of both nvim and nodejs, as apt versions are too old.
  * Place their directories in /opt/ and append 'export PATH="$PATH:/opt/.../bin"' to .bashrc or .zshrc
    * This will add them to the path but with the newer versions.
3. May also have to install python3, python3-pip, python3-venv, curl, git, luarocks
